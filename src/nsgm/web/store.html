Games from release websites

Best available uses BitTorrent when a torrent app is running, and the site's mirrors otherwise, one after another until one works.

Direct downloads at once

The rest wait their turn, so file hosts are not flooded. Torrents queue in the torrent app instead.

Download optional files

Off: extras a release marks optional, such as soundtracks, are skipped.

Keep downloaded files

Off: each download is deleted once its game is installed.

Let installers add DirectX, Visual C++ and other extras

Off: the extra setups a game's installer starts afterwards are stopped, and its file checker too. Most PCs have these already. Each game's page can change it for that game.

Run the store as administrator

Repack installers run as administrator, and only a store with the same rights can stop their extra windows and keep their screens inside the store. One Windows prompt when the store opens, instead of one per game. Takes effect next time it opens.

Check the files after installing

Against the list the release came with, quietly, in place of the installer's own checker window. Takes a while for big games.

No desktop shortcuts

Shortcuts an installer puts on the desktop are removed. Ones already there are never touched.

Don't let games ask for administrator rights

Undoes the "run as administrator" setting installers tick on a game, so it starts without a Windows prompt.

Mute installers

Silences the music some setup programs play while they install. The game itself is never muted.

Catalogues

A catalogue is a list of games in a JSON file, on the web or on this computer, or a website that posts one release per page with its download links. The README has the details.

Read every page of release websites

The whole site is read once, slowly, in the background; after that only new releases are fetched.
